## Known limits / deviations
- **Jump apex:** the S4 row says ≈15125 ±200 (continuous 1650²/(2·90)). Spec §8.2's discrete order
  (`vy -= G; y += vy`, gravity on the takeoff frame) gives exactly **14310** and 36 airborne frames.
  Spec outranks the slice test (AGENTS.md authority order), so the test asserts the discrete value.
- Pushboxes clamp to walls before *and* after separating, so "the one at a wall moves 0" works on the frame
  a fighter walks into the wall.
- `cloneState` uses a JSON round-trip, not `structuredClone` (not in the shared tsconfig's lib); equivalent
  for this plain-data state.
- Jump direction (7/8/9) is read from the frame the jump was input. Timer countdown, hits, pushback and
  projectiles are stubs (S5–S7).
