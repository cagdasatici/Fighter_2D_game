# S8 — Client shell and local two-player debug renderer

Implemented 2026-11-04. Prerequisite S7 is DONE.

## Changes

- Direct local Bolt vs Volt match; 60 Hz accumulator capped at four steps per animation request.
- Logical 640×360 canvas, integer DPR backing scale, CSS letterboxing, camera tracking and event-driven shake.
- Position-only interpolation; drawing reads sim state without modifying it. Debug geometry reuses the simulation's hurtbox and strike-box helpers.
- P1 WASD / U I J K; P2 arrows / Numpad 4 5 1 2; F1 toggles collision overlays. Placeholder bodies remain visible when overlays are off.
- Keyboard listeners, resize listener and animation request have disposal; focus/visibility loss clears keys. HMR/pagehide dispose the app.
- Development-only `window.__kb = { state, step }`; production bundle contains no `__kb` (checked with `rg`).

## Limits

S8 intentionally uses debug rectangles and a fixed roster. Art, menus, audio, input rebinding and touch controls belong to later slices. No new dependencies or simulation changes. Hardware key rollover depends on the keyboard.
