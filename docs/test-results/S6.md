## Interpretations made (spec silent; flag if wrong)
- Special hooks run after physics for fighters not in hitstop (`moveTick`): projectile spawn on `spawnFrame`, heal,
  overload columns, smokeStep, stampedeRoll rebound.
- `heal` applies on move frame 10 (`HEAL_FRAME`); MoveDef has no heal-frame field.
- Projectile limit counts all owned projectiles; it only refuses *specials* with a projectile (supers not gated; S7).
- A multi-hit projectile with `knockdown` knocks down only on its last hit (jadeDragon "last hit launch"); earlier
  hits give hitstun. Against a juggled opponent only that last hit connects.
- Projectile block direction / pushback use the projectile's travel direction (owner side if vx = 0).
- Egg: a direct hit uses up its 1 hit and removes it (no second explosion hit). The explosion box is centred on y 0.
- Command grabs hold the victim `GRAB_HOLD_FRAMES` = 50 frames (gulpGrab) before damage + spit; normal throws stay 30.
- lockOnHit: `hits` includes the first contact; then `hits−1` follow-ups every `interval` frames, then the final hit
  (`finalLaunch`). Follow-ups are unscaled and use no hitstop; the move is frozen during the lock, then plays recovery.
  A blocked first contact ends the active phase early.
- stampedeRoll: a contact (hit or block) may repeat 6 frames after the previous one, max 6; only the 6th launches.
- tailSpin "hits both sides": the box is tested together with its mirror image.
- 360 grab from jumpSquat: allowed while `stateFrame <= 2` (entry frame = 1). The SP macro (…7,8 then HP) may press HP
  on jumpSquat frame 3; check in S14.
- `shurikenFan.H` gets the second star; `airShuriken.H` does not (per-id code is restricted to `shurikenFan.H`).
- Counter stance: parry response is the existing S5 resolution (attacker juggled, Bao 10 frames hitstop); the 8-frame
  palm response animation is render-only. Projectiles count as `mid` for `counter.levels`.

## Known limits / data findings (owner decision needed; data unchanged)
- jackhammerRise, liveWireHop: later hit boxes rise above a grounded opponent's hurtbox, so vs a standing opponent only
  hit 1 lands (60 / 30). As anti-airs the listed totals hold (jackhammerRise 110/140, risingCrane 130).
- hardHatHop: dive box (local y −10..20) is ~90 px up when active, so it passes over crouch hurtboxes (70 px).
- jadeDragon (w 90, vx 900, hitInterval 4): the defender is frozen in hitstop while the projectile keeps moving, so only
  4 of 5 hits connect on a grounded opponent (200, not 250). Affects the S7 super total-damage test.
- Multi-hit supers (overload, stampedeRoll, jadeDragon) use normal combo scaling; S7's "no scaling" total test needs
  a rule for super scaling.
- Supers start only via `startMove` in tests; meter cost, freeze and the input gate are S7.
