## Coverage

- Real authenticated Colyseus SDK clients select characters, ready, receive per-slot start messages, and submit 600 scripted frames below the input rate limit. All frames arrive in confirmations; all ten 60-frame hashes match a local deterministic replay for both clients.
- Missing inputs repeat the previous confirmed bytes after the 100 ms deadline; already-confirmed late input is ignored. A checksum mismatch returns a full snapshot, and an immediate resync is throttled.
- Dropped clients retain a seat, send neutral input during absence, and reconnect to a validated snapshot. A second drop expires after the real 20-second hold and awards the opponent a forfeit.
- A second match runs scripted attacks through KOs to match end; replay reaches the same winner. One rematch vote does not restart; both votes start a fresh match with the same characters, a new seed, reset wins and full hp.
- Protocol unit tests reject invalid input bytes/frames/types and malformed snapshots, require matching snapshot/state frame numbers, accept initial frame-zero snapshots, and verify deterministic data-sensitive content hashing.
- Match input queues and hash history are bounded. Room disposal stops its scheduler, unregisters message handlers, cancels reconnect reservations, and clears stored state.
