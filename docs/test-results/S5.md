## Interpretations made (spec silent; flag if wrong)
- Stun countdown: a stunned fighter acts on the frame after `stun` reaches 0; an attack ends on the frame `moveFrame > total`.
- Button buffer (`buffered`) only drains while the fighter is not in hitstop/superFreeze, so cancels input during hitstop work.
- Normals need a press on the current frame; several buttons on one frame → HK > HP > LK > LP.
- Throw = LP+LK within 2 frames: a grounded LP/LK normal started ≤2 frames earlier upgrades to the throw.
- Throws resolve before strikes; a frame where a throw connects drops strikes. Both throwing on the same frame = tech.
- Thrower recovers to idle when the throw resolves (frame 30); back-throw flag stored in `moveHitMask` bit 1.
- Tech push (6000) and hit pushback use `pushRemain` over 8 frames (per-frame share rounded away from zero).
- Parry (counter stance) resolution is implemented generically from the `counter` field; level filtering is S6.
- Specials start generically (motion + buffered button); projectile spawn, projectile limit, supers, 360-from-jumpSquat: S6/S7 (TODOs).
